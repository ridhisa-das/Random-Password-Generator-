Random Password Generator

Project Overview

This project is a beginner-level Python Random Password Generator. It generates random passwords based on the user's selected password length and character types.

Technologies Used

- Python
- random module
- string module
- Google Colab

Features

- User-defined password length
- Minimum password length of 8 characters
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Requires at least 2 character types
- Input validation
- Generates another password without restarting the program

How It Works

The user enters the desired password length and selects the character types to include. The program combines the selected character sets and randomly generates a password.

Example

Password Length: 12

Selected Character Types:

- Uppercase letters
- Lowercase letters
- Numbers
- Symbols

The program then generates a random password.

Validation

The program rejects:

- Password lengths below 8
- Invalid numeric input
- Fewer than 2 valid character types

How to Run

1. Download "Password_Generator.py".
2. Open it in Google Colab or another Python environment.
3. Run the program.
4. Enter the desired password length.
5. Select at least two character types.
6. The generated password will be displayed.
